# Product Requirements Document (PRD)

## 1. Executive Summary
* **Project Name:** PSX Pocket Advisor & Alert Assistant
* **Target Model:** Gemma 4 (Google AI Studio)
* **Track:** No-Code / Agent Skill Track
* **Target Audience:** Retail investors in Pakistan trading on the Pakistan Stock Exchange (PSX) seeking fast valuation analysis, macro sector insights, and trigger-based price notifications.

---

## 2. Target Sectors & Stock Universe

The agent is scoped strictly to three key blue-chip sectors on the Pakistan Stock Exchange:

1. **Commercial Banks:** `MEBL` (Meezan Bank), `FABL` (Faysal Bank), `HBL` (Habib Bank), `UBL` (United Bank), `MCB` (MCB Bank).
2. **Oil & Gas Exploration:** `MARI` (Mari Petroleum), `OGDC` (Oil & Gas Development Co.), `PPL` (Pakistan Petroleum), `POL` (Pakistan Oilfields).
3. **Fertilizers:** `FFC` (Fauji Fertilizer), `EFERT` (Engro Fertilizers), `FATIMA` (Fatima Fertilizer).

---

## 3. Core Features & Capabilities

### Feature A: Valuation & Stock Recommendation Engine
* Evaluates stocks based on low P/E ratios, high dividend yield history, and relative undervaluation.
* Dynamically compares capital gains potential vs. steady dividend yield profiles across Banks, Oil & Gas, and Fertilizers.

### Feature B: Dual-Trigger Price Alert System
* **Absolute Floor Trigger:** Fires an alert when a stock falls below a specific PKR target price (e.g., `MEBL < 535 PKR`).
* **Percentage Volatility Trigger:** Fires an alert when a stock moves by a set percentage within a trading session (e.g., `-5%` drop or `+10%` surge).
* **Multi-Format Delivery:**
  1. On-Screen Alert Banner (Visual UI notification)
  2. Copy-paste WhatsApp / SMS notification text
  3. Structured JSON Webhook Payload (ready for Zapier, Make.com, or Python SMTP)

### Feature C: Macro Sector Insights
* Incorporates Pakistani macro drivers: interest rate cycles (benefits Banks), PKR devaluation and crude oil prices (benefits Oil & Gas), and gas feed tariffs (impacts Fertilizers).

---

## 4. Offline Simulator Architecture (`index.html`)

To showcase the alert trigger system offline without relying on cloud servers or live APIs:
* **Zero Dependencies:** Pure HTML5, CSS3, and JavaScript.
* **Native OS Notifications:** Utilizes the browser `Notification` API to trigger OS desktop popups on Windows and macOS even without Wi-Fi.
* **Interactive Demo:** Allows selecting target stocks (`MEBL`, `OGDC`, `EFERT`), adjusting threshold triggers, simulating price drops, and viewing live Gemma 4 JSON and WhatsApp notification payloads.
